# 06-先探路再下注

> 对谈观点：看房、买车，只见过一两个选项，就判断不了好坏。像打游戏先开地图，再决定往哪砸资源。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 决策质量取决于看过多少选项：只见过一两个，判断不了好坏
- 先探路（开地图），再下注（砸资源）
- 挑最好的先试一下，能反悔的小实验优先

## 实现思路（规划）

1. 写下要做的决定
2. 用搜索 / 列表工具找 3~5 个候选，不要只看一两个
3. 建一个对比表：成本、收益、风险、不确定性
4. 挑最好的先做一个小实验（能反悔那种），用结果决定是否加注
5. 沉淀「决策前地图模板」：候选清单 + 对比维度 + 小实验设计

## 参考工具

- 推荐：Perplexity、Airtable
- 国内替代：秘塔搜索、飞书多维表格
