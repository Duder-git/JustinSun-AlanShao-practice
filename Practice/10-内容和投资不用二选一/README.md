# 10-内容和投资不用二选一

> 对谈观点：继续发挥自己擅长的（内容），投资另一个领域（投资），不需要成为那个行业的从业者。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 做内容和做投资不是二选一：两条腿走路
- 内容发挥现有优势，投资布局另一个领域，不必亲自下场
- 两个领域分开记账、分开管理，互不污染

## 实现思路（规划）

1. 建两个独立文件夹 / 账本：「内容」和「投资」，各记各的
2. 内容侧：延续擅长的输出（写作 / 视频 / 产品）
3. 投资侧：只记录、研究和资产配置，不冒充从业者
4. 每月各做一次复盘，看两条线的进展和相关性
