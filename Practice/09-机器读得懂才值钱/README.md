# 09-机器读得懂才值钱

> 对谈观点：没被 AI 读到的记录，等于不存在。科研数据、历史资料、资金流，下一步都要变成机器能处理的形式。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 数据的价值 = 可被机器处理的程度：AI 读不到 = 不存在
- 知识、资料、记录，都在往机器能直接读的方向走
- 把常用资料转成 AI 能读的 Markdown / 结构化格式，建立个人知识库

## 实现思路（规划）

1. 盘点常用资料：笔记、PDF、网页、聊天记录
2. 用工具批量转成 Markdown（PDF → 文本、网页 → MD、扫描件 → OCR）
3. 建立统一命名和目录规范（可复用 01 的「收件箱 / 素材 / 日报」结构）
4. 让 AI 基于知识库回答问题，而不是从零生成

## 参考工具

- 推荐：MarkItDown、OCRmyPDF
- 国内替代：MinerU
