# 01-生活AI化：个人 AI 数据库

> 对谈原话（约 00:01:57）：饭前饭后拍照、训练录视频、睡眠数据，全部交给 AI，每天出一份报告。**资料都存成文件，换工具也不丢。**
>
> 本模块实现方法：**利用豆包的跨平台对话能力 + 飞书云盘存储，构建个人 AI 数据库**。健康数据自动导入采用 **HealthExport 实现方案**（HealthExport App + iCloud 云盘自动导出，见下文路径 B），作为本模块的实现方案落地。

## 核心思路

把「生活数据 → AI 分析 → 云盘沉淀」变成一条完整链路：

- **豆包负责「想」**：跨平台对话（手机 App / 电脑客户端 / 网页），随时拍照识别、上传文件、提问分析，生成每日/每周报告
- **飞书云盘负责「存」**：所有原始数据、汇总、日报统一进飞书云盘，构建可追溯的个人 AI 数据库——换工具、换设备都不丢
- **数据入口分三条路径**，覆盖「有电脑」和「没电脑」两种日常

```
                    ┌──────────── 豆包（跨平台对话）────────────┐
 路径A 拍照饮食 ────►│  手机端：拍照识别 / 上传文件 / 随时提问     │
 路径B 健康自动导入 ►│  电脑端：批量解析（parse_healthexport.py） │
 路径C 无电脑上传 ───►│  统一分析 → 生成日报 → 存入飞书云盘       │
                    └──────────────────┬───────────────────────┘
                                       ▼
                    飞书云盘「个人 AI 数据库」
                    ├── 收件箱/  待处理输入（照片、文件）
                    ├── 素材/   已整理数据（健康汇总、饮食记录）
                    └── 日报/   AI 生成的每日/每周报告
```

## 三条数据入口

### 路径 A：饮食 —— 拍照告诉 AI

1. 吃饭前用**豆包 App** 对食物拍照
2. 豆包识别食物种类与大致分量，记录到当日饮食记录
3. 记录存入飞书云盘「素材」文件夹，按月归档
4. 积累一段时间后，让 AI 做饮食复盘：营养结构、热量趋势、可改进项

### 路径 B：健康 / 运动 / 睡眠 —— HealthExport + iCloud 自动导入（有电脑时）

```
iPhone 健康 App（Apple Watch 记录）
  → HealthExport 每天后台自动导出 JSON
  → iCloud 云盘：iCloud~HealthExport/Health/health-YYYY-MM-DD_HHMMSS.json
  → Windows iCloud 同步：C:\Users\2024\iCloudDrive\iCloud~HealthExport\Health\
  → parse_healthexport.py 解析（自动取最新文件）
  → 生成「健康数据汇总_YYYY-MM-DD.md」
  → 上传飞书云盘「素材」→ 豆包据此生成每日健康日报
```

**覆盖指标**：

| 指标 | 内容 |
|---|---|
| 睡眠 | 每天一条：入睡/醒来时间 + 深睡/核心/REM/清醒 分钟数 |
| 运动 Workouts | 类型（步行/力量等）、时长、距离、消耗、来源设备 |
| 步数 | 每日步数 |
| 活跃能量 | 每日千卡 |
| 心率 | 平均 / 最高 / 静息 |

**快速开始（电脑端）**：

```bash
# 1) 用脱敏示例数据跑通流程（仅需 Python 3，无第三方依赖）
python "Practice/01-生活AI化/parse_healthexport.py" --sample

# 2) 解析自己的 iCloud 健康数据（默认路径）
python "Practice/01-生活AI化/parse_healthexport.py"

# 3) 自定义输入 / 输出目录
python "Practice/01-生活AI化/parse_healthexport.py" --input "D:\HealthExport\Health" --output "D:\my-life\daily"
```

生成的 Markdown 在 `Practice/01-生活AI化/output/`（已 gitignore，不会提交个人数据）。把汇总全文复制给豆包（prompt 模板见 `ai-daily-prompt.md`），即可得到健康日报。

**保活检查（数据中断时按此排查）**：

1. iPhone → 设置 → 通用 → **后台 App 刷新** → HealthExport 保持开启
2. 不要长期开启**低电量模式**（会暂停后台刷新）
3. 隔 2~3 天打开 HealthExport 看一眼「Last Export」时间；若太久没更新，点 **Export Now** 手动补一次
4. 首次导出为 30 天全量（sync_type: initial），之后每天增量一个新文件

### 路径 C：无电脑 —— 手机文件主动上传

没有电脑时，用手机完成全流程：

1. 在手机上把需要记录的文件（如 HealthExport 导出的 JSON、健康截图、体检报告等）**发送给豆包 App**
2. 豆包解析 / 总结文件内容，回答你的问题（如「这周睡眠怎么样」）
3. 让豆包把解析结果**保存到飞书云盘**（豆包与飞书打通，直接落盘到「素材」文件夹）
4. 回到电脑前后，同一套数据已在飞书云盘，继续用路径 B 的脚本批量归档

## 个人 AI 数据库结构（飞书云盘）

```
我的生活/
├── 收件箱/     # 所有待处理输入：饮食照片、上传的文件、随手记录
├── 素材/       # 已整理数据：健康数据汇总、饮食记录、原始 JSON
└── 日报/       # AI 生成的每日 / 每周报告，按 YYYY-MM-DD 归档
```

> 命名与归档规则与飞书个人日报系统保持一致；每条记录可标注来源（照片 / HealthExport / 手动上传），便于回溯。

## 说明

- 时间说明：HealthExport 后台刷新由 iOS 择机执行，导出时刻不固定属正常现象，数据按天完整、不丢失。
- 来源说明：所有数据来自 iPhone 健康 App 及 Apple Watch 记录，App 本地处理，无网络上传。
- 隐私说明：本仓库已通过 `.gitignore` 排除个人健康 JSON 与输出文件；`sample/` 中是脱敏示例，可直接删除。
- 本方案为个人健康记录与参考，不构成医疗建议。
