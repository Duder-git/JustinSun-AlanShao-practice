# 01-生活AI化：个人 AI 数据库

> 对谈原话（约 00:01:57）：饭前饭后拍照、训练录视频、睡眠数据，全部交给 AI，每天出一份报告。**资料都存成文件，换工具也不丢。**
>
> 本模块实现方法：**利用豆包的跨平台对话能力 + 飞书云盘存储，构建个人 AI 数据库**。健康数据自动导入采用 **HealthExport 实现方案**（HealthExport App + iCloud 云盘自动导出，见下文路径 B），作为本模块的实现方案落地。

## 核心思路

把「生活数据 → AI 分析 → 云盘沉淀」变成一条完整链路：

- **豆包负责「想」**：跨平台对话（手机 App / 电脑客户端 / 网页），随时拍照识别、上传文件、提问分析，生成每日/每周报告
- **存储层负责「存」**：所有原始数据、汇总、日报统一存为普通文件，构建可追溯的个人 AI 数据库——换工具、换设备都不丢。**默认存飞书云盘；也可选用 Obsidian 服务器（Obsidian Sync，付费，端到端加密多端同步）**
- **数据入口分两条路径**，覆盖「有电脑」和「没电脑」两种日常

```
                    ┌──────────── 豆包（跨平台对话）────────────┐
 路径A 拍照饮食 ────►│  手机端：拍照识别 / 上传文件 / 随时提问     │
 路径B 健康数据导入 ►│  电脑自动解析 / 手机手动发送 → 同步飞书云盘  │
                    └──────────────────┬───────────────────────┘
                                       ▼
                    飞书云盘「个人 AI 数据库」
                    ├── 收件箱/  待处理输入（照片、文件）
                    ├── 素材/   已整理数据（健康汇总、饮食记录）
                    └── 日报/   AI 生成的每日/每周报告
```

## 快速开始：一键提示词

把下面这段**整个复制给你的豆包**，它会按教程「让 AI 帮你搭」的思路，帮你把个人 AI 数据库搭起来（文件夹、日报模板、健康数据入口一次配齐）：

```text
帮我搭一个个人 AI 数据库系统（把生活 AI 化）。
1. 在我的飞书云盘（或 Obsidian 库）建文件夹「我的生活」，里面建 收件箱、日报、素材 三个子文件夹，再写一个 README.md 说明每个文件夹放什么。
2. 设计一个日报模板，包括今天做了什么、精力 1-10 分、睡眠、运动、饮食、一个想法。保存成 日报/模板.md。
3. 以后我说「写日报」，你就读 收件箱 和 素材 里新加的内容（照片、文件、随手记录），按模板生成 日报/YYYY-MM-DD.md，每条结论标出来自哪个文件。
4. 我说「回顾一下」，你就读最近的日报，告诉我什么变好了、什么变差了、接下来最值得改的一件事。
5. 健康数据按两种方式处理，帮我分别落地：
   - 有电脑：HealthExport App 每天自动导出健康 JSON 到 iCloud，电脑上用 parse_healthexport.py 解析成「健康数据汇总_YYYY-MM-DD.md」放进 素材。
   - 没电脑：我在手机上把健康数据文件（或截图）手动发给你，你解析、总结后保存到 素材，并写进当天日报。
6. 饮食数据：我随时拍照发给你，你识别食物后记入当天饮食记录，存入 素材。
做完给我看文件结构和日报模板。
```

> 提示词改编自笔记仓库教程 01「让 AI 帮你搭」段落，将工具从 Claude Code 换成豆包，存储从桌面文件夹换成飞书云盘 / Obsidian，并加入本项目两条健康数据入口。

## 两条数据入口

### 路径 A：饮食 —— 拍照告诉 AI

1. 吃饭前用**豆包 App** 对食物拍照
2. 豆包识别食物种类与大致分量，记录到当日饮食记录
3. 记录存入飞书云盘「素材」文件夹，按月归档
4. 积累一段时间后，让 AI 做饮食复盘：营养结构、热量趋势、可改进项

### 路径 B：健康 / 运动 / 睡眠 —— 自动导入（有电脑）/ 手动发送（没电脑）

**方式一（有电脑）：HealthExport + iCloud 自动导入**

```
iPhone 健康 App（Apple Watch 记录）
  → HealthExport 每天后台自动导出 JSON
  → iCloud 云盘：iCloud~HealthExport/Health/health-YYYY-MM-DD_HHMMSS.json
  → Windows iCloud 同步：C:\Users\2024\iCloudDrive\iCloud~HealthExport\Health\
  → parse_healthexport.py 解析（自动取最新文件）
  → 生成「健康数据汇总_YYYY-MM-DD.md」
  → 上传飞书云盘「素材」→ 豆包据此生成每日健康日报
```

**方式二（没有电脑）：手动发送给豆包，同步到飞书云盘**

1. 在手机上打开 HealthExport（或健康 App），导出 / 复制最新数据文件（JSON），或直接对数据页截图
2. 把文件或截图**发送给豆包 App**，说「帮我解析这份健康数据」
3. 豆包解析出睡眠、运动、步数、心率等摘要后，让它**保存到飞书云盘**「素材」文件夹（豆包与飞书打通，直接落盘）
4. 数据进云盘后，豆包据此写当天日报；回到电脑后 AI 会自动继续归档

**覆盖指标**：

| 指标 | 内容 |
|---|---|
| 睡眠 | 每天一条：入睡/醒来时间 + 深睡/核心/REM/清醒 分钟数 |
| 运动 Workouts | 类型（步行/力量等）、时长、距离、消耗、来源设备 |
| 步数 | 每日步数 |
| 活跃能量 | 每日千卡 |
| 心率 | 平均 / 最高 / 静息 |

> 有电脑时，HealthExport 导出的数据由 AI 自动解析汇总（脚本见本模块 `parse_healthexport.py`），无需手动操作；汇总结果自动存入飞书云盘。

**保活检查（数据中断时按此排查）**：

1. iPhone → 设置 → 通用 → **后台 App 刷新** → HealthExport 保持开启
2. 不要长期开启**低电量模式**（会暂停后台刷新）
3. 隔 2~3 天打开 HealthExport 看一眼「Last Export」时间；若太久没更新，点 **Export Now** 手动补一次
4. 首次导出为 30 天全量（sync_type: initial），之后每天增量一个新文件

## 个人 AI 数据库结构（存储方案）

> **存储二选一**：默认存**飞书云盘**；也可选用 **Obsidian 服务器（Obsidian Sync，付费）**——数据以 Markdown 普通文件保存在 Obsidian 库中，多端加密同步，换工具也能接着读。两种存储下目录结构一致：

```
我的生活/
├── 收件箱/     # 所有待处理输入：饮食照片、上传的文件、随手记录
├── 素材/       # 已整理数据：健康数据汇总、饮食记录、原始 JSON
└── 日报/       # AI 生成的每日 / 每周报告，按 YYYY-MM-DD 归档
```

> 命名与归档规则与飞书个人日报系统保持一致；每条记录可标注来源（照片 / HealthExport / 手动上传），便于回溯。

## 说明

- 时间说明：HealthExport 后台刷新由 iOS 择机执行，导出时刻不固定属正常现象，数据按天完整、不丢失。
- 来源说明：所有数据来自 iPhone 健康 App 及 Apple Watch 记录，App 本地处理，无网络上传。
- 隐私说明：本仓库已通过 `.gitignore` 排除个人健康 JSON 与输出文件；`sample/` 中是脱敏示例，可直接删除。
- 本方案为个人健康记录与参考，不构成医疗建议。
