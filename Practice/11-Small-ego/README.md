# 11-Small-ego

> 对谈观点：张一鸣能一直赢，是因为不管多成功都愿意听年轻人讲。ego 太大，就会被时代甩下。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 保持「小我」：不管多成功都愿意学新东西、听反对意见
- ego 大 = 拒绝反馈 = 被时代甩下
- 让 AI 站在反对者那边反驳你，主动找自己的漏洞

## 实现思路（规划）

1. 写下你当前最确信的一个看法 / 决定
2. 让 AI 扮演「最厉害的反对者」，列出 5 条反对理由
3. 逐条回应，回不上的就是你要补的课
4. 定期（每月）让 AI 评价你的观点是否在进化
5. 沉淀「Decision Journal」：每次重要决定 + AI 反驳 + 你的回应
