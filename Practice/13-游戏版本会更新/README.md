# 13-游戏版本会更新

> 对谈观点：旧版本里最强的打法，新版本可能就没用了。AI 也不是终点。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 世界在持续改版：过去有效的打法会失效，要跟着规则变
- 订阅一手信息源，让 AI 帮你看变化
- 保持对「版本更新」的敏感：技术、政策、平台规则

## 实现思路（规划）

1. 订阅几个一手信息源：官方博客、GitHub Trending、Awesome 列表、行业通讯
2. 让 AI 每周汇总「版本变化」：哪些工具 / 规则 / 打法在变
3. 对照自己的技能与项目，标出「可能失效」和「值得跟进」的项
4. 每季度做一次「版本复盘」，主动更新自己的打法
