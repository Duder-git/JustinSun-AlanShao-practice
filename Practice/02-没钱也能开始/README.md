# 02-没钱也能开始

> 对谈观点：Claude Code 一个月 200 刀用不起？先用便宜的国产 coding 工具。关键是把自己的情况讲清楚，持续喂反馈。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 付费工具不是门槛，先选便宜的 / 有免费额度的工具起步
- 关键不是工具多贵，而是**把自己的情况讲清楚**：经历、兴趣、条件，再持续把结果反馈回去
- 挑一件经常重复的事，用免费额度交给 AI

## 实现思路（规划）

1. 写一份「自我介绍 + 目标」模板（参考笔记仓库 AGENT.md：你现在想解决什么？每周能投入多少时间和钱？）
2. 选一个有免费额度的 AI 编码 / 助手工具
3. 让它拆解一个重复性任务，执行并把结果反馈回去
4. 每周复盘一次 AI 建议质量，形成反馈闭环

## 参考工具

- 推荐：Gemini CLI（有免费额度）
- 国内替代：Kimi Code、Qwen Code
