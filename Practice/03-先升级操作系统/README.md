# 03-先升级操作系统

> 对谈观点：用理论武装自己。对金钱、对财富自由、对万事万物的理解，都得跟着升级。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 「操作系统」指你的认知框架：先升级对世界的理解，行为才会跟着变
- 每天写下一个看法，找资料验证它，用事实更新认知

## 实现思路（规划）

1. 建一个「认知笔记」文件夹，每天写下 1 个看法 / 判断
2. 对每个看法找资料验证（搜索、文献、数据），标注「已验证 / 被推翻 / 待验证」
3. 定期回顾：哪些看法被事实更新了，说明操作系统在升级
4. 用 AI 当验证助手：把你的看法丢给 AI，让它找反例和证据

## 参考工具

- 推荐：Obsidian、NotebookLM
- 国内替代：思源笔记、Kimi
