# 15-多创造少消费

> 对谈观点：不用为生存出卖时间以后，就多创造、少消费。定好大方向，做什么基本都是对的。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 多创造（写教程、做产品、分享），少消费（刷信息、被动娱乐）
- 把刚搞懂的东西写成教程发出去，用输出倒逼输入
- 定好大方向，做什么基本都是对的

## 实现思路（规划）

1. 每搞懂一个新东西，写一篇 500 字左右的教程
2. 发布到公开平台（GitHub Pages / 博客 / B 站 / 公众号）
3. 收集反馈，迭代下一篇
4. 定期复盘：哪些内容被看了、被问了，那就是你的方向
5. 沉淀「创作输出模板」+ 内容发布流程
