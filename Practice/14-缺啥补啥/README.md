# 14-缺啥补啥

> 对谈观点：上班的人不想上班，孙宇晨这种没上过班的特别想上班（最想入职 OpenAI、Anthropic）。换个角色，看到的信息就不一样。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 你缺什么就补什么：缺什么视角，就去扮演那个角色看世界
- 换个角色，看到的信息就不一样
- 落地动作：给自己出一道目标岗位的模拟题，检验能力缺口

## 实现思路（规划）

1. 确定一个你想「补」的角色 / 岗位
2. 给自己出一道该岗位的模拟题（真实任务，不是面试背诵）
3. 用 AI 做考官：出题、批改、指出差距
4. 根据差距找真实场景练习（模拟项目、开源贡献、找人聊）
5. 定期重考，看缺口是否在缩小
