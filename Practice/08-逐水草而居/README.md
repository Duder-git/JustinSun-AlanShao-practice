# 08-逐水草而居

> 对谈观点：哪里能创造最大价值就去哪里。房子、长期承诺越重，越难移动。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 机会是流动的：逐水草而居，哪里价值最大去哪里
- 别太早背上让你动不了的重承诺（房子、长期合同）
- 保持移动能力 = 保持选择权

## 实现思路（规划）

1. 搞清楚你要的机会大多在哪个城市：查目标行业的岗位 / 机会分布
2. 列出现有「重承诺」清单（房租、合同、设备），评估对移动能力的拖累
3. 用 AI 对比 2~3 个候选城市的：机会密度、生活成本、税率、签证 / 政策
4. 做一次「轻移动实验」：短期过去住 / 远程试工，验证后再决定
