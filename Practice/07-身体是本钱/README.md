# 07-身体是本钱

> 对谈观点：把身体当系统维护，持续记录，问题出现前就发现。孙宇晨靠跟 AI 讨论，改掉了对力量训练的偏见。

**状态**：⏳ 待实现（规划中，可复用 01 的数据链路）

## 观点内容

- 身体是长期工作的本钱，当系统维护而不是出问题再修
- 持续记录 → 数据化 → 让 AI 盯趋势，早发现问题早调整
- 健康是长期主义，比短期收入更重要

## 实现思路（规划）

1. **复用 [01-生活AI化](../01-生活AI化/README.md) 的数据链路**：HealthExport + iCloud 自动导入，已有睡眠 / 运动 / 步数 / 心率数据
2. 补充趋势分析：周报 / 月报（睡眠规律、心率趋势、运动负荷）
3. 让 AI 站在「反对者」角度指出健康习惯风险（结合观点 11 Small ego）
4. 制定可量化的健康目标（睡眠时长、步数、训练频率），AI 每周核对
