# 05-商机全球找

> 对谈观点：同一个 AI 包月，阿根廷、土耳其最便宜，美国最贵。别只盯着楼下小卖部，把全世界的人当客户。

**状态**：⏳ 待实现（规划中）

## 观点内容

- 同一个东西在不同国家价格差很多，差价就是机会
- AI 帮你跨过语言障碍，全球找客户 / 找供给
- 从「你这行的人在抱怨什么」入手找需求

## 实现思路（规划）

1. 去海外论坛（Reddit、Quora、X 等）搜你所在行业的抱怨帖 / 提问帖
2. 用 AI 批量翻译、归纳痛点，筛出高频需求
3. 验证需求：Google Trends 看趋势，竞品搜索看供给
4. 用跨境工具试跑一个小闭环（收款、交付），先小规模验证

## 参考工具

- 推荐：Google Trends、Shopify、Wise
- 国内替代：店匠、空中云汇、万里汇
